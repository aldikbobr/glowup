# Проект Глоу Ап

Приложение-план для Алдика: распорядок дня с отметками и серией, тренировки и журнал весов, халяльное меню на неделю, уход за кожей, волосами и ногтями, стиль, осанка, тренажёр дикции и речи, замеры роста и веса, отчёты в WhatsApp и напоминания в Google Календарь.

**Открыть:** https://aldikbobr.github.io/glowup/

**Установить на Android:** открыть ссылку в Chrome → ⋮ → «Установить приложение».

Работает без интернета. Все отметки хранятся только на телефоне; резервная копия — во вкладке «Прогресс».
